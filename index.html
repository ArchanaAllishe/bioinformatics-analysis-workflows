Reproducible Bulk RNA-Seq Analysis

GSE199679 — MP46 versus Normal Melanocytes

Project Overview

RNA sequencing (RNA-seq) provides a genome-wide measurement of gene expression, allowing genes and biological pathways that differ between experimental conditions to be identified.

This report presents an end-to-end bulk RNA-seq analysis using public data from GSE199679. The analysis progresses from raw paired-end sequencing reads through sequencing quality control, alignment, gene quantification, expression-level quality control, differential expression, functional enrichment, and biological interpretation.

The comparison includes six biological samples:

Group Samples
Normal melanocytes (NM) NM_4, NM_5, NM_6
MP46 MP46_1, MP46_2, MP46_3

The analytical steps were developed and validated individually and then connected using Nextflow for reproducible workflow execution. Docker provides controlled software environments, and the final results are presented here using Quarto.

Sequencing Quality Control

Raw paired-end FASTQ files were evaluated with FastQC, and the individual reports were combined using MultiQC 1.35.

FastQC examines individual sequencing files for potential problems such as base-quality deterioration, unusual sequence composition, duplication, adapter contamination, and overrepresented sequences. MultiQC combines these results across all samples, making systematic and sample-specific patterns easier to identify before alignment.

MultiQC Summary

The six RNA-seq samples produced 12 FASTQ files, corresponding to R1 and R2 reads for each paired-end library. Each FASTQ file contained approximately 5 million 101-bp reads.

QC Observation

Overall sequencing quality was suitable for downstream analysis. Per-base sequence quality passed across the FASTQ files, no reads were reported as poor quality, and read length and sequencing depth were consistent across the dataset.

GC content ranged from approximately 47% to 53%. MP46 libraries tended toward the lower end of this range, whereas NM libraries tended toward the higher end. Because this pattern broadly followed the biological groups rather than appearing as an isolated sample-specific deviation, it was interpreted together with downstream expression-level QC rather than automatically considered evidence of contamination.

Sequence duplication ranged from approximately 35% to 51%. Moderate or high duplication can occur in RNA-seq because highly expressed transcripts are sampled repeatedly. PCR amplification or reduced library complexity can also increase duplication. Duplication was therefore considered together with alignment performance, gene counts, PCA, and sample-to-sample correlation rather than being used alone to exclude samples.

Some sequence-content and sequence-length FastQC modules produced warnings or failures. These flags do not automatically indicate unusable RNA-seq data. Sequence-composition biases can arise from library preparation, transcript composition, or other protocol-specific effects and therefore require interpretation in the context of the complete dataset.

Adapter content passed across the dataset. Low levels of Illumina adapter signal were detectable toward the ends of some reads, but these levels were not sufficient to trigger an adapter-content warning or failure. A small number of overrepresented sequences were also detected and were interpreted according to their abundance and possible origin rather than automatically removed.

QC Conclusion

The combined FastQC and MultiQC assessment supported proceeding to alignment without additional adapter or quality trimming.

This decision was supported by consistently good per-base sequence quality, the absence of reads flagged as poor quality, passing adapter-content results, consistent sequencing depth, and the absence of a broad sample-specific sequencing-quality failure.

FastQC warnings were retained and documented rather than automatically corrected because warnings can reflect expected characteristics of RNA-seq libraries. Their significance was subsequently evaluated using independent downstream QC measures including alignment performance, gene assignment, PCA, and sample-to-sample expression correlation.

Read Alignment

Following raw-read QC, paired-end reads were aligned to the GRCh38 human reference genome using STAR.

Alignment determines where sequencing reads originated in the genome. RNA-seq requires a splice-aware aligner because many reads span exon-exon junctions created during RNA splicing.

STAR produced coordinate-sorted BAM files representing the genomic alignments for each sample.

Sample Uniquely mapped reads

MP46_2 94.31%

Unique mapping rates ranged from approximately 88.3% to 95.2%, supporting successful alignment across all six samples.

The automated Nextflow workflow reuses the resulting BAM files for downstream processing.

BAM Processing and Library Strandedness

The coordinate-sorted BAM files were indexed using SAMtools, allowing downstream tools to access genomic regions efficiently.

Library orientation was then assessed using RSeQC infer_experiment.py.

RNA-seq libraries may preserve information about the strand from which a transcript originated. Using the wrong strandedness setting during gene quantification can assign reads incorrectly and alter gene counts.

The libraries were identified as reverse-stranded paired-end RNA-seq. featureCounts was therefore run using:

-s 2

Gene Quantification

Aligned fragments were assigned to genes using featureCounts with the GENCODE v48 gene annotation.

Alignment determines where reads map, whereas gene quantification determines how many aligned fragments correspond to each annotated gene. The resulting raw integer counts provide the input required by DESeq2.

The featureCounts output was processed with Python to remove unnecessary annotation columns, simplify sample names, maintain consistent sample order, and create an analysis-ready gene-by-sample count matrix.

The initial matrix contained:

78,894 genes × 6 samples

Expression-Level Quality Control

Raw-read QC determines whether the sequencing reads are technically suitable for analysis. After gene quantification, expression-level QC provides another independent assessment of sample relationships and biological replicate consistency.

DESeq2 variance-stabilizing transformation (VST) was used to generate expression values suitable for PCA and sample-correlation analysis.

Principal Component Analysis

Principal component analysis summarizes major sources of expression variation across thousands of genes.

The first two principal components explained:

PC1 = 88.79%
PC2 =  3.73%

PC1 clearly separated the NM and MP46 groups, while biological replicates clustered according to condition.

This indicates that the largest source of expression variation in the dataset corresponds to the biological comparison.

Sample-to-Sample Correlation

Pearson correlation was calculated between samples using transformed expression values.

Within-group correlations were high:

NM:       approximately 0.96
MP46:     approximately 0.96–0.98

Correlations between the two groups were lower:

approximately 0.56–0.64

The agreement among biological replicates and the lower correlation between groups were consistent with the PCA results.

Together, these independent expression-level QC analyses supported retaining all six samples for differential-expression testing.

Differential Expression

Differential-expression analysis was performed with DESeq2.

DESeq2 models RNA-seq counts using a negative-binomial statistical framework while accounting for sequencing-depth differences and biological variability among replicates.

The model was:

Design:     ~ Group
Contrast:   MP46 vs NM
Reference:  NM

A positive log2 fold change therefore represents higher expression in MP46, whereas a negative value represents higher expression in NM.

Significant differential expression was defined as:

adjusted p-value < 0.05
AND
|log2FoldChange| ≥ log2(1.5)

The fold-change threshold corresponds to an expression difference of at least 1.5-fold in either direction.

Integrated Interpretation

The individual analysis stages provide complementary evidence about the dataset.

Raw-read QC indicated that the sequencing data were suitable for alignment without additional trimming. STAR subsequently produced high unique mapping rates across all samples.

Expression-level QC provided an independent check after gene quantification. PCA showed clear separation between NM and MP46, while sample correlation showed strong agreement among biological replicates.

DESeq2 identified 6,816 genes meeting the predefined statistical and fold-change thresholds, with 3,495 showing higher expression in MP46 and 3,321 showing higher expression in NM.

Functional enrichment then translated these gene-level differences into broader biological patterns. Genes higher in MP46 were associated primarily with cell-division-related processes, whereas genes higher in NM showed enrichment for extracellular matrix, adhesion, antigen-processing, and immune-related functions.

Together, the raw-read QC, alignment results, expression-level QC, differential-expression analysis, and functional enrichment provide a consistent view of substantial transcriptional differences between the two groups.

These results describe associations within this dataset and do not by themselves establish causal biological mechanisms.

Reproducible Workflow

The analysis was first developed and validated as individual Python, R, and command-line steps and then connected using Nextflow DSL2.

RNA-seq workflows contain many dependent processes and intermediate files. Nextflow manages these dependencies automatically, tracks process inputs and outputs, caches completed work, and allows interrupted or previously completed analyses to continue using -resume.

The current Nextflow implementation reuses the resulting STAR BAM files and automates the downstream analysis.

Docker provides controlled software environments for workflow processes, reducing dependency on software installed directly on the host computer.

The project also demonstrates Linux and SLURM research-computing concepts, including shared project storage, Environment Modules, resource requests, job submission, and job monitoring.

These components serve complementary roles:

Component Role
Git / GitHub Version-controlled code and documentation
Docker Reproducible software environments
Nextflow Automated workflow execution
Linux / SLURM Research-computing environment
Quarto Reproducible and shareable reporting

Together, they connect the biological analysis with the computational practices needed to make the workflow reproducible and reviewable.

Conclusion

This project demonstrates an end-to-end bulk RNA-seq analysis progressing from raw paired-end sequencing reads to biological interpretation.

Raw-read QC was interpreted rather than treated as a simple PASS/FAIL decision. MultiQC supported proceeding without unnecessary trimming, and subsequent alignment, PCA, and sample-correlation analyses provided independent checks of data and sample quality.

Differential-expression analysis identified substantial transcriptional differences between MP46 and NM, while functional enrichment provided biological context for those changes.

Nextflow automation, Docker environments, version-controlled analysis code, Linux/SLURM computing practices, and Quarto reporting bring these individual steps together into a reproducible and reviewable bioinformatics workflow.

# Integrated Interpretation

The individual analysis stages provide complementary evidence about the
dataset.

Raw-read QC indicated that the sequencing data were suitable for alignment
without additional trimming. STAR subsequently produced high unique mapping
rates across all samples.

Expression-level QC provided an independent check after gene quantification.
PCA showed clear separation between NM and MP46, while sample correlation
showed strong agreement among biological replicates.

DESeq2 identified **6,816 genes** meeting the predefined statistical and
fold-change thresholds, with 3,495 showing higher expression in MP46 and 3,321
showing higher expression in NM.

Functional enrichment then translated these gene-level differences into
broader biological patterns. Genes higher in MP46 were associated primarily
with cell-division-related processes, whereas genes higher in NM showed
enrichment for extracellular matrix, adhesion, antigen-processing, and
immune-related functions.

Together, the raw-read QC, alignment results, expression-level QC,
differential-expression analysis, and functional enrichment provide a
consistent view of substantial transcriptional differences between the two
groups.

These results describe associations within this dataset and do not by
themselves establish causal biological mechanisms.

# Reproducible Workflow

The analysis was first developed and validated as individual Python, R, and
command-line steps and then connected using **Nextflow DSL2**.

RNA-seq workflows contain many dependent processes and intermediate files.
Nextflow manages these dependencies automatically, tracks process inputs and
outputs, caches completed work, and allows interrupted or previously completed
analyses to continue using `-resume`.

The current Nextflow implementation **reuses the resulting STAR BAM files** and
automates the downstream analysis.

**Docker** provides controlled software environments for workflow processes,
reducing dependency on software installed directly on the host computer.

The project also demonstrates **Linux and SLURM** research-computing concepts,
including shared project storage, Environment Modules, resource requests, job
submission, and job monitoring.

These components serve complementary roles:

| Component | Role |
|---|---|
| Git / GitHub | Version-controlled code and documentation |
| Docker | Reproducible software environments |
| Nextflow | Automated workflow execution |
| Linux / SLURM | Research-computing environment |
| Quarto | Reproducible and shareable reporting |

Together, they connect the biological analysis with the computational
practices needed to make the workflow reproducible and reviewable.

# Conclusion

This project demonstrates an end-to-end bulk RNA-seq analysis progressing from
raw paired-end sequencing reads to biological interpretation.

Raw-read QC was interpreted rather than treated as a simple PASS/FAIL
decision. MultiQC supported proceeding without unnecessary trimming, and
subsequent alignment, PCA, and sample-correlation analyses provided independent
checks of data and sample quality.

Differential-expression analysis identified substantial transcriptional
differences between MP46 and NM, while functional enrichment provided
biological context for those changes.

Nextflow automation, Docker environments, version-controlled analysis code,
Linux/SLURM computing practices, and Quarto reporting bring these individual
steps together into a reproducible and reviewable bioinformatics workflow.
